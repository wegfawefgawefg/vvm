# Resources

Local paper copies for VVM design work.

## Curiosity

- `papers/pathak-2017-icm.pdf`
  - Deepak Pathak, Pulkit Agrawal, Alexei A. Efros, Trevor Darrell.
  - "Curiosity-driven Exploration by Self-supervised Prediction"
  - <https://arxiv.org/abs/1705.05363>

- `papers/burda-2018-large-scale-curiosity.pdf`
  - Yuri Burda, Harri Edwards, Deepak Pathak, Amos Storkey, Trevor Darrell,
    Alexei A. Efros.
  - "Large-Scale Study of Curiosity-Driven Learning"
  - <https://arxiv.org/abs/1808.04355>

- `papers/reizinger-2019-attention-icm-rational-curiosity.pdf`
  - Patrik Reizinger, Marton Szemenyei.
  - "Attention-Based Curiosity-Driven Exploration in Deep Reinforcement Learning"
  - <https://arxiv.org/abs/1910.10840>

I did not find a single canonical paper named "ICM2". The attention paper uses
labels like `ICM2xAtt`; the large-scale curiosity paper is the more important
ICM follow-up for VVM because it documents both curiosity-only learning and the
stochastic/noisy-state failure mode.
